**问：双擎科技有哪些机器人产品？**

双擎科技（杭州）有限公司（英文名 Futural Robotics）以 AMR、多模态感知与融合、VLA 大模型及自研 EI-Core 框架为核心技术，面向医院、药企、工厂提供机器人产品与调度系统。整体可分为六大类：

## 1. 迎宾 / 导医机器人
<ul>
<li>小晴（FW-24M）：23.8" 屏，支持 AI 大模型、人脸识别、展厅讲解、带路、业务咨询；</li>
<li>Peggy（FW-24M）：迎宾讲解机器人；</li>
<li>小双（FW-27M）：27" 屏智能交互机器人；</li>
<li>小青 / 小擎（FW-22M）：具身智能 / 智能人形服务机器人。</li>
</ul>
## 2. 医院配送 / 运输机器人（FTR 系列）
<ul>
<li>封闭式：FTR300-C / FTR50-C / FTR50-C3，用于药品、物资院内封闭式配送；</li>
<li>开放式 / 顶升式：FTR300-J / FTR50-OT / FTR50-OL，用于多层开放或顶升转运；</li>
<li>标本运输：FTR50-O / FTR50O-OD，用于检验科标本转运；</li>
<li>内镜运输：FTR30-OTE / FTR50-OLE，用于内镜中心器械转运；</li>
<li>赤兔（封闭式）：F2，配送运输机器人。</li>
</ul>
## 3. 工厂转运机器人
<ul>
<li>FTR300-J（300kg 顶升式）：产线 / 仓储物料顶升转运；</li>
<li>FTR50-OL：智能制造柔性物流。</li>
</ul>
## 4. 消毒机器人
<ul>
<li>净宝 FS01：过氧化氢 / 次氯酸雾化消毒；</li>
<li>消消 FS03：过氧化氢 / 次氯酸雾化，出雾量 2250ml/h；</li>
<li>海葵 / FU1（U1）：UVC 紫外线消毒，获 CE 认证。</li>
</ul>
## 5. 客户定制机器人
<ul>
<li>迪安诊断标本运输定制机：FTR50O-OD；</li>
<li>污染物监测机器人 FEM10-AM、拍照机器人 FCA10 等。</li>
</ul>
## 6. 软件产品
<ul>
<li>**RCS 机器人智能控制系统**：多机任务编排、路径规划、与 LIS 等业务系统对接；</li>
<li>**知识库问答系统**：面向机器人端的知识问答能力。</li>
</ul>
## 共同特点
六大类产品共享"软硬一体 + 全流程模块化定制"能力——从外观设计、硬件开发到算法部署端到端交付，并可统一接入 RCS 调度系统，支撑整院 / 整厂的多机协同。
